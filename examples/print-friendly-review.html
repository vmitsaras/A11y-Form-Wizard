How the printable view works

Semantic structure

  • The review is an <article> with labelled sections.
  • Each question and answer uses a description-list term and description.
  • The content remains complete when JavaScript is unavailable.
Copy the markup pattern 
<section aria-labelledby="contact-heading">
  <h2 id="contact-heading">Contact</h2>
  <dl>
    <div>
      <dt>Email</dt>
      <dd>alex@example.com</dd>
    </div>
  </dl>
</section>

Print presentation

  • Screen-only controls use one explicit print-hidden class.
  • Print removes decorative surfaces and restores black text on white.
  • Answer groups avoid page breaks where the browser supports it.
Copy the print CSS pattern 
@media print {
  .print-hidden { display: none !important; }
  .review { border: 0; box-shadow: none; }
  .review-group {
    break-inside: avoid-page;
    page-break-inside: avoid;
  }
}
