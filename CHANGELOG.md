# Changelog

This package uses Changesets for release notes.

## 1.0.0 - 2026-09-11

### Added

- Accessible, progressively enhanced multistep form behavior for semantic HTML forms.
- Per-instance navigation, validation, focus management, progress updates, and live announcements.
- Single-step and stacked display modes, review-and-edit steps, and configurable choice auto-advance.
- Public TypeScript API, generated declarations, base styles, and an optional `a11y-form-validator` integration.
- Reduced-motion support, responsive demo pages, usage documentation, and automated accessibility contract tests.
